# 校園拾光（原名 AI 照片篩選器）

校園活動照片的 AI 挑片、命名、相簿庫與成果包工具。單一網頁檔，照片只在老師自己的電腦處理。

- **目前版本**：2026v7（2026-10-28）
- **網站版**：這個 repo 推到 `main` 後，Netlify 會自動部署（`index.html`）。
- **單檔版**：`versions/校園拾光_2026v7_2026-10-28.html`，下載後直接用 Chrome／Edge 打開也能用。

## 怎麼用
1. 用**電腦版 Chrome 或 Edge** 打開網站。「存進相簿庫」「存到資料夾」需要這兩種瀏覽器。
2. 想像程式一樣用：按網址列的「安裝」，或 ⚙️ 設定 → 關於 →「📲 安裝成 App」，桌面就會出現「校園拾光」圖示。第一次開過之後，沒網路也能篩照片；只有 Gemini 寫文案時才需要網路。
3. 操作說明：頁首的 ❓。

## 個資與隱私
- 照片**不會上傳到這個網站**。網站只把工具本身（壓縮後約 0.3 MB）送到瀏覽器。
- 會連網的只有這三種，而且都要老師按了才送：
  - ✨ Gemini 寫文案：送縮小的照片和活動名稱。
  - 🌐 查地標名稱：只送座標。
  - 舊的 Google Drive 同步。
- 詳細清單在工具裡的「🔒 資安與隱私」。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 網站版主程式（＝目前版本） |
| `versions/` | 各版本單檔（檔名含版本與日期） |
| `manifest.webmanifest`、`sw.js`、`icon-*.png` | 安裝成 App（PWA）、離線快取 |
| `netlify.toml` | Netlify 設定：純靜態，`index.html`、`sw.js` 不快取，更新才會立刻生效 |
| `docs/各月份常見活動_範例_大橋國小.csv` | 各月份常見活動的範例清單；其他學校可以改成自己的，再從 ⚙️ 設定 → 🏷 分類 匯入 |

## 更新方式
新版本：把新的 html 放進 `versions/`，同一份覆蓋 `index.html`，`sw.js` 的 `VERSION` 改成新版本號，推到 `main`。
