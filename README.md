## 怎麼用
1. 用**電腦版 Chrome 或 Edge** 打開網站。「存進相簿庫」「存到資料夾」需要這兩種瀏覽器。
2. 想像程式一樣用：按網址列的「安裝」，或 ⚙️ 設定 → 關於 →「📲 安裝成 App」，桌面就會出現「校園拾光」圖示。第一次開過之後，沒網路也能篩照片；只有 Gemini 寫文案時才需要網路。
3. 操作說明：頁首的 ❓。
4. Android 手機：安裝成 App 後，在相簿選照片 →「分享」→「校園拾光」就能直接匯入（iPhone 請用「選照片」）。

## 個資與隱私
- 照片**不會上傳到這個網站**。網站只把工具本身（壓縮後約 0.3 MB）送到瀏覽器。
- 會**送出資料**的只有這三種，而且都要老師按了才送：
  - ✨ Gemini 寫文案：送縮小的照片和活動名稱。
  - 🌐 查地標名稱：只送座標。
  - 舊的 Google Drive 同步。
- 🖼 海報、🎬 回顧短片都在老師的電腦裡做，照片不離開電腦。短片選了內建配樂時，會**下載**那一首音樂（網址只有曲目代號，不送任何資料）。
- ✨ 海報 AI 封面插圖（按了才送）：只送活動名稱與標語文字給 Gemini 畫圖，不送照片。
- 「📲 直接分享」是把縮好的照片交給你在手機上選的 App（LINE、FB…），由那個 App 送出。
- 手機分享進來的照片只暫存在手機瀏覽器，匯入後立刻刪掉；「最近整理記錄」只存在這台電腦的瀏覽器，不含照片。
- 詳細清單在工具裡的「🔒 資安與隱私」。

## 資安（2026v25＋第二輪 2026v26＋第三輪 2026v27，2026-11-06 檢查）
- **XSS**：照片檔名、別人的相簿庫 index.json、匯入的整理記錄、記錄器分享連結、AI 回傳文字，一律當純文字顯示；自動測試把每個來源都換成攻擊字串走過每個畫面，0 個被執行。
- **Gemini API Key**：只存在老師自己的瀏覽器；送出時放在 `x-goog-api-key` 標頭，不放網址；程式裡沒有寫死任何 Key。
- **供應鏈**：JSZip、face-api.js、onnxruntime-web、heic2any 版本鎖定＋SRI（SHA-384，與 npm 原檔比對）；YuNet 模型比對 SHA-256。
- **CSP**：網頁只准連到 jsDelivr、GitHub（模型）、Google 字型、Gemini、Google 登入／雲端硬碟、OpenStreetMap；禁止 `<object>`、`<base>`、表單送出。
- **網站標頭**（`netlify.toml`）：禁止被嵌入、nosniff、Referrer 只送網域、禁止相機／麥克風／定位、HSTS。
- **第二輪**：相簿庫 index.json 與整理記錄讀進來先檢查格式（學年度、日期、座標只收正確格式，丟掉 `__proto__`）；CSV 匯出防 Excel 公式注入；分享入口不收別的網站送來的照片，分享進來先秀縮圖、按「匯入」才匯入。
- **2026v29–v31**：海報、短片全在本機做；mp4-muxer 鎖版本＋SRI、只在做短片時載入；內建配樂下載後比對 SHA-256；CSP 只多開 `audio/bgm/` 這一層。
- **第三輪**：照片 EXIF 文字一律當純文字；onnxruntime-web 另外下載的 `.mjs`／`.wasm` 比對 SHA-256 才使用；匯入／匯出 ZIP 路徑每層清理（防 ZIP slip）；不收 SVG；CSP `connect-src` 收緊到路徑（Gemini 只准 generateContent、Drive 只准 files API、OSM 只准 reverse）；`versions/` 舊版不放在網站上。
- 無追蹤碼、Cookie、廣告、遙測；本工具自己的程式沒有 `eval`（HEIC 轉檔函式庫內部會用，CSP 因此開放）。

## 更新方式
新版本：把新的 html 放進 `versions/`，同一份覆蓋 `index.html`，`sw.js` 的 `VERSION` 改成新版本號，推到 `main`。

## 想再精修影片：Concat
回顧短片做好後，想加字幕、旁白、更多特效，可以用免費開源剪輯軟體 **[Concat](https://github.com/jub0t/Concat/releases)**（Windows／Mac／Linux／Android，有繁體中文）：
- 全部在自己電腦處理，**影片不上傳**；不用帳號、沒有浮水印。
- 本機自動上字幕（Whisper）、文字轉語音旁白、去背、轉場與標題特效、多軌剪輯，輸出到 4K。
- 目前是 beta 版；Windows 第一次開若被 SmartScreen 擋，按「其他資訊 → 仍要執行」。
- 它是 AGPL-3 授權的獨立軟體，校園拾光只放連結、沒有整合它的程式碼，兩者之間也沒有連線。
